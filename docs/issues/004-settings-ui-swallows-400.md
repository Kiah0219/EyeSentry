# 004 · 前端设置同步忽略非 2xx 响应

- 严重度：P1
- 状态：未修复
- 范围：`static/index.html`
- 发现：2026-10-25 项目审计

## 现象

白名单勾选或置信度滑块的请求被服务端拒绝（400）时，页面没有任何提示，控件仍显示新值；后续轮询又不会覆盖已打开面板的本地状态，UI 与服务端从此分叉。

## 位置

[static/index.html:414](../../static/index.html#L414) `scheduleSettings()`：只 `try/catch` 网络异常，从不检查 `res.ok`。

## 根因

把「fetch 成功」当成「设置成功」。`fetch` 对 4xx/5xx 不抛错。

## 建议修复

检查 `res.ok`；失败时读取 `detail` 并用现有 `hint()` 提示，同时从 `/api/status` 重新同步控件值（或回滚本次改动）。若与 003 一起修，服务端应保证失败请求无副作用。

## 验收

- 人为让 `/api/settings` 返回 400：页面出现提示，控件回到服务端值。
- 正常请求：无额外提示，行为不变。
