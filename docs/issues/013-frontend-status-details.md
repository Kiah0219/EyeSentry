# 013 · 告警计数、初始通道闪烁、截图 404 无兜底

- 严重度：P2
- 状态：未修复
- 范围：`static/index.html`
- 发现：2026-10-25 项目审计

## 现象

1. 顶部「告警」数字来自当前列表长度（最多 50），不是总告警数；告警超过 50 条后数字停在 50。
2. `config.yaml` 配成 `channel: web` 时，页面首次渲染到第一次轮询之间（约 1 秒）下拉固定显示「本体」，会闪一下。
3. 截图被 `MAX_SNAPSHOTS` 裁掉后，旧告警记录仍在列表里，缩略图 404，页面显示破图。

## 位置

- 计数：[static/index.html:542](../../static/index.html#L542) `setAlertCount()` / [static/index.html:544](../../static/index.html#L544)
- 初始通道：[static/index.html:628](../../static/index.html#L628) 轮询里才同步；页面初始值是 `device`
- 缩略图：[static/index.html:520](../../static/index.html#L520) 没有 `onerror` 兜底

## 建议修复

- 计数：用 `/api/status` 的总数（需要 005 把计数做成 O(1)），或把文案改成「最近 50 条」。
- 初始通道：在第一次轮询完成前禁用下拉，或由服务端渲染初始值。
- 缩略图：`img.onerror` 时替换成占位块 / 隐藏图片；与 005 的三者同寿命策略一起做。

## 验收

- 告警超过 50 条时，计数与实际总数一致或文案明确是「最近 N 条」。
- 配置为 web 时首次加载不闪「本体」。
- 截图缺失时列表不出现破图，点开大图也不报错。
